# 🎒 Lost & Found Management System (IT ELECT 4)

A full-stack Lost and Found web application built for campus item tracking, reporting, and claims management, integrated with a Vercel backend deployment.

## 🚀 Live Deployment & Repositories

* **Live Frontend Application:** [https://lorenz-allen26-itelect4-project-it-seven.vercel.app](https://lorenz-allen26-itelect4-project-it-seven.vercel.app)
* **Live Backend API:** [https://gt-4-fullstack.vercel.app](https://gt-4-fullstack.vercel.app)
* **Frontend GitHub Repository:** [LorenzAllen26/LorenzAllen26-itelect4-project-IT4B-Main2](https://github.com/LorenzAllen26/LorenzAllen26-itelect4-project-IT4B-Main2)
* **Backend GitHub Repository:** [LorenzAllen26/gt-4-fullstack](https://github.com/LorenzAllen26/gt-4-fullstack)

---

## ✨ Features

* **Item Reporting:** Report lost or found items with detailed titles, descriptions, categories, and campus locations.
* **Category & Status Filtering:** Filter reported items instantly by category (*Electronics*, *Personal Items*, *Documents*, *Found*, *Lost*) or view your tracked items via the dedicated **Claimed Items** tab.
* **Claim Management:** Submit and track item claims linked to your active session.
* **Responsive Dashboard:** Dark-mode optimized UI built with Tailwind CSS and React TypeScript.

---

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript, Tailwind CSS, Vite
* **Backend:** Node.js, Express / Serverless API routes
* **Deployment & Hosting:** Vercel
